# Datamatics

[Datamatics](https://datamatics.rorz.io) generates rows of bars and glyphs in the browser. **Refresh** draws a new composition. **Download PNG** saves the current one at 1584 × 396 pixels.

Run `bun run dev:datamatics` from the repository root to develop on port 4448. Use `bun run deploy:datamatics:dry` to check the production build and `bun run deploy:datamatics` to publish it.

Migrated from [rorz/datamatics](https://github.com/rorz/datamatics).
